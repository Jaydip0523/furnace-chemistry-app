# Furnace Chemistry Control — Android

Android wrapper for the Furnace Chemistry Control web application.

## Automatic APK build

Every push to `main` runs the **Build Android APK** workflow. Download the generated `furnace-chemistry-control-apk` artifact from the repository Actions page and install `app-debug.apk` on Android.

The Android app opens:
https://furnace-chemistry-control.chhatralajaydip8.chatgpt.site

On first use, enter the deployed Google Apps Script `/exec` URL in the application's Setup screen.
